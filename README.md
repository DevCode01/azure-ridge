# Azure Ridge

**Go** · **v0.1.0**

_Prime number finder using the Sieve of Eratosthenes_

---

## Features

- Sieve of Eratosthenes up to any limit
- Formatted output, 10 primes per line
- Count summary

## Installation

```bash
git clone https://github.com/DevCode01/azure-ridge.git
cd azure-ridge
```

## Usage

```bash
go run main.go 1000
```
